# Third-party code

Bundled third-party code keeps its own licence:

- qrcode-generator by Kazuhiko Arase: MIT, header of `app/js/vendor/qrcode.js`
- Figtree font: SIL OFL 1.1, `app/fonts/OFL.txt`

Babel standalone 7.26.4 (MIT) is not bundled: the app downloads it from jsDelivr (or unpkg) when it
converts a marketplace extension.
