Log in with Spotify

Spotify only lets each TuneDeck key be used by 5 accounts. Everyone else sets up their own free key once below. It takes about 3 minutes and needs Spotify Premium.

Set up your own Spotify key

  1. Open the Spotify developer dashboard and log in with your Spotify account. Accept the terms if it asks. Open Spotify dashboard
  2. Create an app. Name: TuneDeck. Description: anything, e.g. “My TV”.
  3. Under Redirect URIs, paste this address and tap Add:
    …
  4. Under Which API/SDKs, tick Web API and Web Playback SDK. Agree to the terms and tap Save.
  5. On your new app’s page, open Settings, copy the Client ID and paste it here:
  6. Then log in. When your phone warns the connection isn’t private, tap Advanced → Continue: that’s your TV’s own certificate. Log in with Spotify

Only the Client ID goes to the TV. Never paste the Client secret anywhere.
